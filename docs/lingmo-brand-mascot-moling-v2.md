# LingMo 品牌形象 V2：墨灵 MoLing

## 核心判断

上一版猫头鹰偏硬、偏“设定稿”，缺少亲和力。LingMo 的产品气质更适合一个轻盈、安静、低打扰的陪伴形象，而不是复杂动物结构。

## 新形象

**名称：墨灵 MoLing**

墨灵是一个由“墨滴 + 纸面 + 灵感弧”构成的小助手。它不强调强拟人，也不靠夸张动作吸引注意，而是像笔记旁边安静出现的一点灵感。

## 为什么更贴合 LingMo

- “墨”对应 Markdown 写作、本地笔记、沉稳可靠。
- “灵”对应 AI 辅助、知识检索、灵感捕捉。
- 暖白脸部像纸张，降低工具冷感。
- 琥珀弧线延续现有 app icon，形成品牌连续性。
- 圆润墨滴轮廓比猫头鹰更简洁，适合启动页、空状态、头像和图标。

## 视觉规则

- 主色：炭黑 `#363D40`
- 辅色：暖白纸色 `#F8F1E8`
- 点睛色：琥珀 `#F5A623`
- 气质：温暖、聪明、安静、可靠
- 禁忌：高饱和、强科技机器人、复杂道具、表情包化
