# LingMo 品牌形象：墨墨 Momo

## 项目定位提炼

LingMo 是一款跨平台 Markdown 笔记应用，核心体验是“低摩擦捕捉、安静写作、AI 辅助知识整理、本地优先可信赖”。它不是热闹的效率看板，也不是冷冰冰的技术终端；品牌气质更接近一张安静书桌旁的智能助手。

关键词：智能、温暖、可靠、内容优先、低打扰、本地信任。

## 吉祥物概念

**名称：墨墨 Momo**

**物种设定：墨枭**

墨枭是由“纸张、墨水、知识检索光环”组成的 LingMo 专属品牌形象。它不像机器人那样强调工具感，也不像普通宠物那样偏娱乐；猫头鹰天然关联夜间写作、知识、观察和安静陪伴，很适合笔记与知识整理产品。

## 视觉元素

- **身体**：哑光炭黑，来自 LingMo 现有图标的 `#363D40`，象征墨水、本地数据和稳定底座。
- **脸部**：暖白纸面心形轮廓，象征 Markdown 写作、笔记页面和温暖陪伴。
- **胸口墨点**：一个小型墨池/镜头圆点，代表 AI 记忆、RAG 检索和本地知识库。
- **头顶琥珀弧线**：沿用现有 app icon 的 `#F5A623` 弧线，像思考光环，也像被高亮的知识线索。
- **翅膀**：折纸/书签形态，呼应文件、卡片、片段记录和知识归档。
- **眼神**：圆润、专注、低攻击性；表达“我在这里帮你整理”，而不是“我在催你操作”。

## 品牌性格

墨墨应该给人的第一感受是：

- 聪明，但不炫技。
- 温暖，但不幼稚。
- 可靠，但不沉重。
- 安静陪伴，而不是主动打扰。

## 使用场景

- App 启动页、欢迎页、空状态。
- AI 对话等待、RAG 检索中、索引完成提示。
- 新手引导：快速捕捉、写作、知识库搜索、同步状态。
- 官网/应用商店主视觉。
- 社区头像、GitHub README、发布公告。

## 不建议的方向

- 不做强科技机器人形象，避免偏冷、偏企业 SaaS。
- 不做高饱和花哨配色，避免抢笔记内容的视觉焦点。
- 不做夸张表情包化动作，避免破坏 LingMo 的安静写作气质。
- 不加入大量装饰线条、渐变背景或复杂道具。
