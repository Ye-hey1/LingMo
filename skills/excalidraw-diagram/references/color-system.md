# 语义配色系统

让 Claude 不用每次重新想"这个节点用什么颜色"，按节点的**语义类型**直接查表。

配色风格：暖色（珊瑚/米白/桃粉）为主调，冷色（深青绿/低饱和蓝）作功能性区分。
整体低饱和、有温度感，适合技术展示和讨论场景。roughness 默认 0（精确风格）。

---

## 核心映射表

| 语义 | backgroundColor | strokeColor | labelColor | 典型节点 |
|---|---|---|---|---|
| **用户 / 外部输入** | `#b8d4d4` | `#464650` | `#1e1e1e` | 用户、Client、外部 API、第三方系统 |
| **业务 / 处理逻辑** | `#c3e0fe` | `#464650` | `#1e1e1e` | Service、Handler、Controller、Agent |
| **数据 / 存储** | `#f5ede0` | `#464650` | `#1e1e1e` | Database、Cache、File、KV Store |
| **决策 / 分支** | `#e8c0a8` | `#464650` | `#1e1e1e` | if/else、Gateway、Router、Condition |
| **成功 / 输出** | `#548484` | `#464650` | `#ffffff` | 成功结果、响应、输出 |
| **错误 / 告警** | `#ffc9c9` | `#464650` | `#1e1e1e` | 错误分支、异常、告警 |
| **中性 / 通用** | transparent | `#464650` | `#1e1e1e` | 未分类 / 占位 / 注释 |

**labelColor 规则（必须严格遵守）**：

```json
"label": { "text": "节点名称", "fontSize": 16, "strokeColor": "<labelColor>" }
```

- **浅色背景**（包括决策橙 `#e8c0a8`、错误粉 `#ffc9c9`、所有 pastel 扩展色板）→ 文字统一用 `#1e1e1e`（黑色）
- **深色背景**（backgroundColor 较深，如 `#548484`、`#1a5f5a`）→ 文字用 `#ffffff`（白色）

> 早期版本曾给决策节点用深棕 `#6b3a2a`、错误节点用深红 `#6b1a1a`（与背景同色系），但实测对比度不够稳定，且和其他节点不统一。现在所有浅色背景一律黑字。

**判断深浅的简单标准**：backgroundColor 的亮度（L值）低于 50% 时视为深色，用白色文字；高于 50% 用黑色文字。实际操作中，`#548484`、`#1a5f5a`、`#2d5c5c` 这类明显偏深的颜色用白字，其他 pastel 色一律黑字。

## 背景 Zone（分层标注）

架构图分层、区域标注用，**opacity 40-50**，作为淡淡的底色：

| Zone 类型 | backgroundColor | strokeColor | 用途 |
|---|---|---|---|
| Frontend / UI 层 | `#f5ede0` | `#d4846a` | 前端、客户端范围 |
| Logic / Service 层 | `#d8eaea` | `#1a5f5a` | 业务逻辑、处理层 |
| Data / Tool 层 | `#1a5f5a` opacity 20 | `#1a5f5a` | 数据存储、工具层 |

```json
{
  "type": "rectangle",
  "backgroundColor": "#f5ede0",
  "fillStyle": "solid",
  "opacity": 45,
  "strokeColor": "#d4846a",
  "strokeWidth": 1,
  "roughness": 0,
  "roundness": { "type": 3 }
}
```

## 风格档位

| 档位 | roughness | fillStyle | fontFamily | strokeWidth | 适用 |
|---|---|---|---|---|---|
| **sketch-soft（默认）** | 2 | solid | 5 (Excalifont) | 2 | 默认风格：手绘抖线 + 色块保留语义色 |
| sketch | 2 | hachure | 5 (Excalifont) | 2 | 草稿感要更强、xkcd 风、斜纹填充 |
| formal | 0 | solid | 2 (Helvetica) | 1 | 技术文档、PPT、需要"精确感"时 |

**默认使用 sketch-soft**（roughness=2 + solid + Excalifont + strokeWidth=2）。线条
手绘抖动 + 色块保留语义色 + 粗描边让 wobble 在缩略图可见。

**切 formal**：用户明确说"正式/精确/文档风/打印/严谨"。
**切 sketch（hachure 斜纹）**：用户明确说"草稿/xkcd 风/斜纹/明显未定稿"——斜纹会
盖掉语义色的识别度，仅在需要强烈"草图感"时用。

**关于 fontFamily**：Excalifont 只覆盖拉丁字符，中文会 fallback 到系统字体。中文为主
的图即使切 sketch 系列档，文字也是规整的——靠 roughness=2 让节点形状和线条带手绘
抖动感，纯英文图才能看到文字本身的手绘感。这是当前已知权衡。

**关于 strokeWidth**：sketch 系列用 2（wobble 在 1px 细线下几乎不可见），formal 用 1
保持精致。

## 深色模式映射（备用）

用户明确要求深色主题时切换：

| 语义 | backgroundColor | strokeColor |
|---|---|---|
| 用户 / 外部 | `#0f3d3a` | `#464650` |
| 业务 / 处理 | `#0d2a4a` | `#464650` |
| 数据 / 存储 | `#3d2e1e` | `#464650` |
| 决策 / 分支 | `#4a3020` | `#464650` |
| 成功 / 输出 | `#2a4444` | `#464650` |
| 错误 / 告警 | `#4a1a1a` | `#464650` |

深色模式在 cameraUpdate **之前**加深色背景矩形：

```json
{
  "type": "rectangle",
  "id": "darkbg",
  "x": -4000, "y": -3000,
  "width": 10000, "height": 7500,
  "backgroundColor": "#1a1a2e",
  "fillStyle": "solid",
  "strokeColor": "transparent",
  "strokeWidth": 0
}
```

深色模式文字用 `#e8e0d8`（暖白）或 `#9ab8c0`（灰蓝），不要用纯白或深灰。

## 扩展色板（自由配色场景）

当节点不属于任何语义类型，或用户要求"每个节点不同颜色"、"渐变叙事"风格时，从这个色板里选颜色，不要自己发明。

| 色名 | backgroundColor | 搭配 strokeColor | 搭配文字色 |
|---|---|---|---|
| 浅紫 | `#CBCADB` | `#464650` | 默认 |
| 浅蓝 | `#C8DEFA` | `#464650` | 默认 |
| 浅橙 | `#FAD4C0` | `#464650` | 默认 |
| 浅绿 | `#C8E6C9` | `#464650` | 默认 |
| 浅黄 | `#FFF3BF` | `#464650` | 默认 |
| 浅粉 | `#F4C4B4` | `#464650` | 默认 |
| 浅青 | `#D4E8E1` | `#464650` | 默认 |
| 浅米 | `#F0E6D3` | `#464650` | 默认 |
| 浅冰蓝 | `#D0E8F4` | `#464650` | 默认 |

**使用规则**：
- 同一张图里从色板里顺序取色，不要跳跃选色
- 相邻节点不要用过于相近的颜色（比如浅蓝和浅冰蓝不要相邻）
- strokeColor 统一使用 `#464650`
- 扩展色板全部是浅色，节点文字统一用 `#1e1e1e`（黑色）

**禁止自由发明颜色**：不在语义色表或扩展色板里的颜色，不要使用。特别禁止高饱和度原色作为节点填充，如 `#8b5cf6`（纯紫）、`#22c55e`（纯绿）、`#3b82f6`（纯蓝）等。

### 节点语义难以分类

节点既像"处理逻辑"又像"外部服务"时：
- 看**位置**：主流程内用业务蓝，边缘/外部用用户青绿
- 看**图的焦点**：讲业务流用业务蓝，讲系统集成用外部色

一个节点只用一种语义色，不要混用。

### 用户指定了品牌色

以品牌色替换珊瑚色系（`#d4846a` 相关），青绿系（`#1a5f5a`）保留作冷色对比。

## 配色自检

画完前快速过一遍：
- [ ] 相邻节点颜色是否有足够区分度？
- [ ] strokeColor 和 backgroundColor 对比度是否清晰？
- [ ] 箭头颜色是否跟语义场景匹配？
- [ ] 一张图内语义色种类 ≤ 5 种？
- [ ] 所有节点 roughness 是否统一？
