# 工作日报周报技能包 · 使用说明

## 一、这是什么

一个给 AI 产品经理用的日报 / 周报写作技能。已安装到
`C:\Users\ThinkPad\.zcode\skills\work-report`，桌面这份是同内容副本，
可直接分享给同事（对方拷到自己的 `.zcode\skills\` 下即可用）。

## 二、怎么用

在 ZCode 里直接说话触发，不需要记命令：

**生成周报（从多份日报提炼）**
> 把这三份日报里叶做的工作提炼出来，写成周报，飞书格式

**生成日报**
> 帮我写今天的日报：上午战略发展部二次调研完成需规，下午政讯通联调...

**只补某几段**
> 我周报的前两节写好了，帮我补客户评价、问题汇总、商机线索和复盘

**换交付形式**
> 这份周报导出成 Word / 压到一页 / 改成表格版

也可显式调用：`/work-report`

## 三、内置规则要点

**周报七段式**（顺序固定）
总览 → 重点工作进度及成果 → 客户评价与意见 → 问题汇总 →
下周计划(P0/P1/P2) → 客户动态与商机线索 → 复盘与业务思考

**日报四段式**
需求调研情况 → 研发实施情况【上线/联调/开发/优化】→ 员工运行情况 → 待办事项【责任人】

**核心机制**
- 归属过滤：多人日报里只提取你负责的部分，他人主导的写"配合/跟进"
- 事实对齐：跨天同一件事合并成一条，状态取最新
- 阻塞项清零：周初待办的解决情况单独成段，容易漏但价值高
- 增项识别：清单外新需求自动转成商机线索
- 坏消息保留：延期、返工必须写，并在复盘里给流程层面的根因
- 飞书场景零表格：所有对比信息改成"加粗小标题 + 列表"

## 四、文件说明

| 文件 | 作用 |

| `references/rules.md` | 细则：事实对齐四步、各章节写法、措辞对照表 |
| `templates/weekly.md` | 周报占位符模板 |
| `templates/daily.md` | 日报占位符模板 |
| `examples/weekly-sample.md` | 真实范例（2026.07.20-24）+ 七条规则标注 |
